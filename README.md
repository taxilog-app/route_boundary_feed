# route_boundary_feed

タクシー運行アプリ（route_timer_app）の**丁目境界レイヤ**用データ配信ハブ。
営業圏ごとにフォルダを分け、GitHub Pages で静的配信する。

- `fukuoka/` … 福岡交通圏
- `tokyo23/` … 東京特別区・武三交通圏（東京23区＋武蔵野市＋三鷹市）

各フォルダに `choume_fill.geojson`（丁目・塗り）と `machi_frame.geojson`（町枠）。
出典：国勢調査2020 小地域（町丁・字等別）境界データ（総務省統計局／e-Stat）を加工。

## `pref/{都道府県コード}/` … 全国の逆ジオコーディング用（2026-07-25 追加）

座標→住所（例: 大阪駅→「大阪市北区梅田三丁目」）をアプリ内で解くためのデータ。
運転手は自分の営業圏の1県ぶんだけ取得して端末にキャッシュする。

- `choume_fill.geojson` … 丁目ポリゴン（`n`=町名+丁目, `b`=bbox）
- `chome_ward.json` … 各丁目の市区町村名（ポリゴンと同順・同件数の配列）

47都道府県・231,370丁目（1県あたり1.5〜13.7MB、gzip で概ね1/5）。

上の `fukuoka/` `tokyo23/` は地図表示用（町枠つき・交通圏のみ）で用途が別。
こちらは表示用プロパティを落とし、県まるごとを収録している。

生成手順は route_timer_app の `tools/build_choume_boundary_pref.sh`。
出典：国勢調査2020 小地域（町丁・字等別）境界データ（総務省統計局／e-Stat）を加工。
